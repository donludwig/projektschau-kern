What is inside

For people looking for information

  • Cards and timeline: the same projects in two views

  • Two filters: by area and by type of project

  • Selection as a link: every view can be passed on

  • Two languages: for example German and English

For people maintaining and deciding

  • One structure for all projects: easy to write, easy to compare

  • A colour per area: one colour is enough, the rest is derived

  • Clean printing: only the projects, without menus

  • Free software: free of charge, runs on your own server

What is KERN?

KERN is the open design standard for digital services of the German public administration: ready-made building blocks that make federal, state and local websites look consistent and usable for everyone. KERN is open source and free of charge. It was built for public authorities and their IT service providers. Associations, initiatives and foundations that offer services to the public can use it as well.

And Projektschau?

A community contribution: several KERN building blocks assembled into an overview of projects. It is meant for the KERN catalogue, where the community shares its additions.

In use, and how to set it up

In use at a regional network

Projektschau comes from a project overview of a network in Brandenburg, where it shows more than 40 projects from the region and runs in WordPress.

I am currently working on a WordPress plugin with a form and preview for editors. It uses the same data format and has not been released yet.

Ready in three steps

  1. Pick a web page, the KERN kit comes with the package

  2. Write the projects as a list into one file

  3. Include three files, the documentation shows how

Try the demo

It runs in the browser with 32 fictitious projects, without installation or sign-up. The package contains all files and the documentation.
