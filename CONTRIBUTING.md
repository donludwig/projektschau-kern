# Mitwirken

Rückmeldungen sind willkommen, besonders zu Barrieren und zu Fehlern im Renderer.

- **Fehler und Barrieren:** als Issue, mit den Vorlagen „Fehler“ oder „Barriere“. Hilfreich sind die Ansicht, der Browser und gegebenenfalls das Hilfsmittel.
- **Sicherheitslücken:** nicht als Issue, sondern vertraulich, wie in [`SECURITY.md`](SECURITY.md) beschrieben.
- **Pull Requests:** Die Prüfskripte aus [`AGENTS.md`](AGENTS.md) müssen bestehen, die Regeln dort gelten auch für Menschen. Größere Änderungen bitte vorher als Issue besprechen.

Beiträge stehen unter derselben Lizenz wie das Projekt, der EUPL-1.2.

---

# Contributing

Feedback is welcome, especially on accessibility barriers and renderer bugs. Report bugs and barriers as an issue using the templates; report vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md). Pull requests must pass the check scripts listed in [`AGENTS.md`](AGENTS.md); please discuss larger changes in an issue first. Contributions are licensed under the EUPL-1.2, like the project.
